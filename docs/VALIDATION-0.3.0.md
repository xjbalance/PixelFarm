## 本版验证重点

- 来信逐字显示、补全文、真实触屏选择、取消不提交、读完后保存动机。
- 全部首章阶段依序可完成；未备齐物品不扣费，重复领取与越级推进被拒绝；取消交付不发奖。
- 从农场路牌实际进入村庄；断桥河面真实物理阻挡，修好后实际走过河面。
- 公共设施全部完成前，即使食材足够也不能跳过建设进入庆典；共建必须靠近村中木板。
- 真实触屏建井、多物品一次性扣费、重复施工与材料不足的无副作用处理。
- 共仓影响真实种子购买金额；水井修改实际农田；茶座恢复体力；每日额度与下一天重置。
- 18:00 前不能完成庆典，长椅可等到傍晚；三位村民实际在广场出现；结局选择影响对白与灯饰。
- 三处村庄记忆收入手记，完整存档恢复选择与发现；未知、重复、越级、未来日期等非法数据整体拒绝。
- 雨水在昨天成长结算后补给；新翻土可接雨；晴天恢复人工照料，不额外生成生长日。
- 操作辅助通过实际交互浇水、采收；可关闭辅助恢复精确工具选择。
- 1280×720、1600×720、1280×960 的共建/地图/人物/记忆和选项对话保持可见；原有安全区、双指和后台检查继续通过。
- 手机原始触点可滚动长人物手记，建设按钮重建后释放触点；滚动取消误点，裁切区域外按钮不能响应。
- 显式启动配乐/雨声播放器后校验静音；渲染测试和正常清理没有音频资源泄漏。无界面默认不启动常驻音乐。

## 发现并修正

触屏按钮回调重建面板后访问空 Viewport、条件对白 Array[String] 的运行时类型冲突、关闭鼠标模拟后的原生手记滚动缺失、滚动按钮触点未释放，以及长 WAV 在 Godot 4.3 强制退出时尚未清理的问题已修复。旧失败日志保留，最终结果以上表和最终日志为准。
