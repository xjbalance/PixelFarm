## 路径与动画协议

下列路径中的`<variant>`为上述四个ID之一：

正常与仪式资源都按`down / left / right / up`四行排列；每行四个行走帧，建议6FPS循环；`idle_*`为该方向第0帧的静态待机。左右各有独立帧，不通过无条件镜像替代。

32版本脚底坐标为`(16,45)`，居中Sprite偏移`(0,-21)`；64版本为`(32,90)`与`(0,-42)`。应沿这些固定锚点接入现有控制器，不能每帧按非透明包围盒重新居中。农具动作仍使用现有动作协议，不把这里的静态待机冒称新增呼吸动画。

## 头像、立绘与仪式派生

头像从给定参考图里的正面头像框内部裁切，只保留人物正面，不包含列标题、色板或背面辅助图。立绘直接使用该角色自己的主全身插画；多边形遮罩去除标题、说明文字、色板、辅助头像和旁边像素小人。保留裁切区的原羊皮纸纹理，空白处用原图纸面小样补成统一矩形底卡，避免生硬的多边形纸边；它是有纸面背景的正式立绘卡面，不是新绘制的纯透明插画，也不是放大64像素小人冒充立绘。

四套仪式精灵由相同角色的原64像素精灵表做轻量奶油白、蓝紫和暖金配色派生，并添加小型衣扣；不改变原透明轮廓和脚底，上部36行头发与面容逐字节保留，32版本再用最近邻得到。它们是可用于现有仪式的同角色配色，不冒称已制作完整原创婚礼服装或独立礼服动作。
