# 游戏中切换人物形象

打开右上角菜单，点击「切换人物形象」。可以随时预览男主角、女主角，点击「使用男主角形象」或「使用女主角形象」确认；返回则取消预选，回到当前游戏菜单。

男主角对应女版小京，女主角对应男版小京。沿用方案 C 的行走形象、头像、立绘和仪式配色，所有显示位置共用同一外观状态。小京仍然是原来的同一位 NPC，任务、关系、婚姻、婚后记录与奖励均不重置。

确认只更新 `appearance`，使用原有临时文件与备份机制保存当前旅程；没有调用新游戏初始化、换场景或完整读档恢复。金币、物品、体力、时间、农田、住宅、家具、矿洞与操作设置保持原值。保存失败则恢复原主角和小京形象，保留当前预选，允许重试或返回。预览期间进入后台只保存已经确认的原形象。

其他菜单、读档、后台、退出、午夜结算、工具动作及资源事务进行中不接受切换。钓鱼和温室正式仪式须先完成。选择页沿用现有触点归属、多指与混合设备过滤，不把选择或确认释放事件传给地图。取消读档或日结算中的选择页不会重新打开菜单。

原有「新游戏 · 重新开始」仍然单独确认和备份；「切换人物形象」不进入该流程。当前存档继续使用 v25，不增加字段；缺失外观字段的旧存档仍按既有迁移规则恢复，之后也可以在菜单中切换。

实际窗口检查发现并修复了首次打开选择页过高的问题：自动换行文字初始宽度不足会临时抬高面板最小高度；容器排版稳定后，现在会重新按安全区布局，不再把确认区挤出屏幕。这是尺寸变化驱动的更新，不增加每帧布局刷新。

新增 **126 项状态检查、126 项实际窗口检查**全部通过；原角色选择、外观、新游戏流程、回家和新旧存档的 **283 项状态回归**、相关 **199 项窗口回归**通过。六次独立进程验证包含 v24 迁移、v25 恢复及损坏主档的备份恢复，没有把重复执行次数累计为不同测试。完整记录见 [TEST-CHARACTER-SWITCH.json](TEST-CHARACTER-SWITCH.json)。
