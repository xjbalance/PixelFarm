# 0.7.0经营经济模型

实际执行`python3 tools/simulate_070.py`：读取当前作物、统一物品目录、气候、钓鱼、畜牧、厨房、生态和永久建设配置；每个独立经营渠道10,000组×28游戏日，随机种子707020。原料均以放弃出售的机会成本计入，加工只记增量利润。**这是明示操作/成功率/季节假设的模型，不是真人试玩，也不是单玩家最优联合排程。**

| 独立模型：每日净金 | P10 | P50 | P90 |
|---|---:|---:|---:|
| 12–30格当季农田 | 93.21 | 164.79 | 289.29 |
| 有日限/耗饵/操作失败的钓鱼 | 61.29 | 112.29 | 160.51 |
| 六只成年鸡牛羊 | 103.86 | 120.00 | 127.21 |
| 四队列加工增量机会利润 | 22.36 | 23.71 | 25.14 |

不能将这些中位数简单相加。相同食材不可既算出售又算加工；建造/动物/鱼竿投入、先前解锁工时、菜单阅读、体力恢复/增益的最优安排和真人操作差异没有完整纳入。正常渠道没有让原种田失去价值。生态首次恢复投入摊28日约−14金/日，收益主要是环境、成长与探索开放。

所有新料理售价低于其原料机会成本；跨日加工最高加价率约14.3%，受设备、原料、队列、批数和时间限制。四笔贸易单农业方向含8金额外奖励后的机会差为22/24/32/28金，共享三日间隔，最大额外约10.67金/日且仍需真实新产与交实物。巡灯机会差约3金/日，另需3体力/步行；周末共餐与巡灯共享日限。探索和生活方向不锁农业/社区，额外补给也有稳定唯一领取状态。

新模块没有正数钻石奖励配置。永恒星鲤和特殊收藏售价0、不换钻石；春铃花种年度赠/限购，花每次消耗一粒种子，撤苗只返一粒，采收不返种。重复领取、跨日、满包、读档与迁移均有运行回归。原钻石仍来自已有高阶矿业/探索链，原婚礼1314条件不改。

模型没有给出新的小京从新档实际完成小时数。旧0.6.1的终局时长假设不能直接套到新恢复、四季和社交系统，也不为追200小时而降低掉率或强迫空等。后续需完整真人多季试玩与自愿提供的本地日志校准。
