# 版本记录

## 0.4.0 — 像素世界：那些没有寄出的信

- 更名为《像素世界》/ Pixel World，Android显示名与版本更新；保留包名、原签名和旧用户数据目录。
- 第一章《河水带走的名字》：旧信、残缺地图、桥墩/维修调查、茶屋留言册、风车货运簿与两张可选便条。
- 数据驱动主线任务与独立调查事实；修桥要求人物交流，后段以建设生活变化推进；三种发展方向影响推荐任务、对白和种子奖励，其他方向不锁死。
- 简单NPC日程、桥边/井边/茶座活动、真实碰撞网格行走、对话暂停、风灯永久装饰。
- 小京隐藏支线基础：520成功播种与一次夜信、独立角色/头像、三属性、每日限额、12任务、7记忆、五段关系事件。
- 五种试炼原型、可重复基础矿道路线盘、九格机关、钻石/原矿、周期委托与加工、遗匣；温室修复和确认婚礼事务、婚后生活与520日回信。
- schema6逐步迁移v1–v5，操作模式默认点击移动，旧建设和奖励不重置，历史播种不推算；婚姻/试炼中断可恢复。
- 默认点击移动、AStarGrid2D自动寻路、智能交互；菜单自由切换备用摇杆，切换立即取消旧移动/交互，模式写入存档并在重启恢复。
- 三图真实碰撞网格、桥梁/树石刷新、动态NPC占位与跟随、UI归属和多指过滤；到达后只调用原规则一次。
- 扩展原自动化回归、跨进程婚姻与操作模式存档测试、平衡模拟和当前文档；Android versionCode升为5，签名不变。

未完成：150–250小时实际内容与试玩、完整多层矿洞和终局试炼打磨。点击系统已接入，触控手感仍需手机验收。没有Android或Windows真机验收。详见[本版测试](VALIDATION.md)、[小京数值](XIAOJING.md)和[剩余内容](PROJECT-STATUS-0.4.0.md)。

## 0.3.0 — 共建河湾

- 原创完整第一章，以建设更好村庄为主轴：供菜、修桥、三项公共设施、聚餐和风灯之夜。两处选择影响后续对白和结尾装饰，三处可探索往事收录进手记。
- 新增河湾村、河流、真实修复后通行的旧桥、风车、茶屋、木作坊和公共广场；周砚、阿禾与林芽共同参与，风灯夜实际在广场相聚。
- 水井每日引水浇灌、共仓永久种子优惠、茶座每日恢复体力；顺序自由，主线要求共建全部完成。
- 对话头像、逐字、回答选项、取消与完成提交分离；手机触摸长列表、手记地图、人物档案和进度追踪。
- 细雨天气、次日预报、操作辅助、工具图标、农活粒子、草叶/蝴蝶/岸边波纹、夜间萤火、场景过渡和原创循环音乐。
- 统一地表色板，丰富原创建筑、树冠、人物衣着，新增可见设施和陈设碰撞。
- 存档 v3 保存主线、选择、探索、村庄建设和每日福利，迁移 0.1 / 0.2 经营进度；手机后台保存和同签名更新。
- 修复触屏回调重建面板后的空 Viewport、条件对白数组类型、长列表无触屏滚动、滚动中误触按钮以及循环声音退出清理。

验证及 APK 实际结果见 [本版报告](VALIDATION.md)。尚未进行 Android 真机验收；后续章节、完整 NPC 寻路日程、四季和畜牧钓鱼未实现。


## 0.2.0 — 农场修缮与河谷委托

- 原有 14 棵树和 5 处石堆成为可采集资源。斧头/镐、剩余耐久、体力消耗、掉落入包、受击反馈、解除碰撞与数日后再生组成完整循环。
- 再生时若玩家站在原位置，延后到后续换日，避免角色被新障碍困住。
- 背包增加材料页，木材和石料可在种子摊出售，也用于修缮与交付委托。
- 小屋东侧新增修缮台：工具架让采集每次造成 2 点伤害，引水渠每天自动浇灌 12 格，卧室让体力上限提升至 130。
- 小屋东侧新增委托板，包含三份带前置关系的原创委托；完整交付、金币/种子/好感奖励与一次性领取。
- `J` 或右上「委托」打开随身追踪手记，办理与领取须到委托板。
- 林芽每天首次交谈增加 2 好感，完成委托获得额外好感，并显示不同关系称呼。
- Android 系统返回键关闭当前面板，或在游戏中打开菜单，避免意外退出。
- 工具栏扩展为八格；新按钮、修缮页、委托页和材料页保留原生多点触控。
- 多物品交易先在副本中校验，再整体提交，防止奖励背包满、金币封顶或材料不足时发生部分扣除。
- 存档 schema 更新为 2，保存采集耐久/再生日期、设施、委托、好感与当日交谈记录；兼容 0.1.0 存档。读入旧档不改原文件，下次保存升级格式并保留旧版备份。
- 自动保存成功时不再覆盖奖励提示；读取没有引导记录的存档会正确重置引导文案。
- Android/Windows 导出过滤器加入全部游戏 JSON 数据；已实际导出 PCK 并在不提供源码的临时目录启动验证。

验证：161 项集成断言通过；新增状态跨进程恢复、旧存档跨进程迁移和原文件备份通过。实际渲染截图覆盖新增界面和三种横屏比例。

历史补充：0.2.0 后来已成功生成 APK；未生成 Windows EXE 或完成手机真机性能验收。NPC 日程、天气季节、畜牧钓鱼、更多地图和背景音乐尚未实现。
