# 《像素世界》0.8.2《活力牧场》开发报告

本轮以 `244c379`（0.8.1《丰收匠心》、存档v29）为基线，完成鸡蛋反馈、正式鸭养殖、鸡鸭牛羊真实活动、独立大牧场、96×64主农场和永久开垦。开发分支 `development/0.8.2`；恢复点 `backup/0.8.1-before-0.8.2`。用户的 `need/`、真实存档及原农场坐标保留。

## 实际问题与最终行为

原鸡蛋并非完全没有生产：成年鸡在合格照料日结算1枚，每只最多暂存3份，原窗口基线验证了收进背包与防重复领取。问题是库存藏在动物菜单里，没有明显鸡窝入口。现已在主农场鸡鸭舍及后方暖舍设置同一库存的鸡窝，显示鸡蛋、鸭蛋数量；满包整笔保留，收取后切换空窝，播放像素收取反馈与原收获音效。

原动物先向固定站位慢移，之后仅在站位周围作约5×4像素摆动，只有两帧单向图。新版使用真实世界坐标、四方向原生图集和 IDLE / WANDER / GRAZE / REST / INTERACT / RETURN_HOME 状态；速度分别为鸡32、鸭25、牛18、羊23像素/秒。行走、停歇与吃草节奏分开，个体随机种子不同。点击动物保持同一身份并短暂停步，到达后打开原照料系统，结束后恢复活动。

六只牛返舍的实际回归发现了同伴阻挡及室内绕路走到屋外的问题，已以缓存16像素动物路径网格、避开同伴的合法锚点和独立暖舍路径范围修复。每个牧场的32像素面积网格与16像素AI连通分量逐格核验，所有被计入面积的格子都有可达锚点。寻路只在选目标或重试时执行，不逐帧全图搜索；隐藏地图停止高频AI，返回视野后从保存位置继续真实走动。

雨雪、冬季及18:00后回暖舍；晴朗/多云08:00–14:00沿原规则开栏。视觉啄地不会另给免费饲料或产物。备用摇杆/E、默认点击移动均遵守真实墙体视线，不能在54像素内隔墙喂食、抚摸或收蛋。

## 主农场四倍扩建与永久开垦

地图原点仍是(0,0)，旧48×32区域不平移，从东、南扩至96×64。新增土地接入原农田、果树、工坊、道路、家具和大型建筑DIY；生产田继续使用稳定逻辑坐标键与稀疏字典，容量扩至6,144。原60格、已播种作物及逻辑/物理搬迁映射保留。相关社交/共建/节日的农活坐标容量同步扩展，任务条件和奖励没有重写。

东原耕作地、南原工坊地、果木花园和自由庭院仅作为图纸规划提示，玩家可以自行改变用途。实际演示包含6处跨旧边界地块的点击行走、翻土、播种、浇水、成长、收获，以及在清除石头的地块建造磨坊。242格小麦/胡萝卜/土豆窗口样例同样使用种子消耗与正常日成长；样例使用隔离测试资本。

普通树、石堆、树桩、灌木、野草与大石堆具有稳定ID、工具、耐久和掉落。大石堆需要原有付费精制工具架。原树4木、原石3石的产量与工具伤害升级不变。清除后取消图像、碰撞和导航占用，通知原自动保存；主农场不再跨日重生，也不留下不能继续清理的树桩图。

原湖岸装饰灌木与旧石堆重叠的情况保留了两个原坐标：普通点击继续操作附近剧情设施；手动选择镐子可优先清理石堆，之后选择斧头清灌木。全部过程有真实站位和视线，不绕过墙或工具要求。森林、村庄、矿洞各自的原刷新规则保留。

原九格HUD和相机模式保持。边缘观察余量与原生地面衬边使最边缘土地不被固定HUD遮住；衬边不计入地图面积，实际碰撞、农田、权限与图纸边界始终为96×64。
