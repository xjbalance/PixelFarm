# 存档兼容：v1–v21（0.7.0）

游戏版本0.7.0，当前schema为**21**：剧情重构引入v4，小京引入v5，操作模式引入v6。序号没有混用。`FarmSaveSchema.normalize()` 深复制输入并逐步迁移，校验成功才恢复；再次规范化当前v21返回相同数据。

| 旧字段 | 处理 |
|---|---|
| coins/items | 原样保留，不在迁移中交换库存 |
| plots | 保留翻土、作物、天数、浇水 |
| player/location/day/minutes | 保留位置、地图和时间；真实碰撞恢复检查沿用 |
| stamina/selected/journal/muted | 保留体力、工具、教学和声音 |
| progress | 保留农场修缮、委托、好感与当日交谈 |
| resources | 保留采集耐久与再生日期 |
| story | 保留stage、旧选择与seen，旧memory/tomorrow结局仍合法 |
| village | 保留已建项目与每日使用额度 |

v3→v4只新增`letters`：facts、completed、direction、legacy_review。用原有stage标记已经结算的任务，不执行建造、扣材料或发奖励。stage≥3视作旧供菜教学已经完成，stage≥4保留调查前置免补课，stage≥5保留旧修桥；未通关玩家可接着新剧情推进。旧教学journal中的成功农活可成为新主线事实；**这不用于推算小京播种次数**。

旧首章通关保持stage8、所有建筑和奖励。信箱/屋内木盒提供回顾，环境线索仍可读。风灯架`future`事件只新增一次发展方向与对应种子，不再给庆典120金。旧设施不会再次收费。

v4→v5新增`xiaojing`，初始化：

- plants/plant_serial：0，不推测历史次数；成功农田提交后加1，展示信号不计数。
- 神秘信、解锁、好感/信任/羁绊、每日交谈/赠礼/活动、关系事件、任务/记忆/试炼。
- 钻石/原矿单独数量（0–999999），不改原有999普通堆叠上限。
- 试炼新田产出、有效销售净收入、勘探位置/气囊/已采矿晶、机关状态。
- 温室、求婚/婚姻、结婚日、婚后事件、第520日彩蛋。

校验拒绝未知ID、重复任务/记忆/矿晶、非法属性与日期、矛盾婚姻状态、非法矿道坐标等。婚礼确认是同一状态事务：条件重查→扣1314钻石→设置婚姻与日期→提交保存；取消和重复调用都不扣费。钻石不是普通商店商品。

v5→v6只新增`control_mode`，枚举值为`tap`（点击移动）和`joystick`（虚拟摇杆）。旧档一律默认`tap`，不会凭当前设备猜测模式。金币、物品、地图、主线、小京进度及全部旧字段原样保留；非法枚举整份拒绝。切换后立即取消路径、待交互和摇杆向量，提交自动保存；加载模式不会额外发出保存请求。路径、目标节点、触点归属和一次手动工具优先标志不保存，重启从静止状态开始。迁移可重复执行。

保存仍为`user://farm_save.json`，临时文件+flush+原档`.bak`+更名流程保留。迁移不立即覆盖磁盘，下一次保存写v21，上一份原文件成为备份。更名不会删除或主动迁走存档。测试均在临时用户目录运行，不触及真实玩家文件。

Godot更名后显式保留旧用户目录：Linux `godot/app_userdata/Pixel Farm · 风芽农场`，Windows/macOS `Godot/app_userdata/Pixel Farm · 风芽农场`，均相对各平台数据根。Android的Godot用户目录由应用私有目录提供，包名和签名继续使用原值。覆盖更新仍需真机验收；不要卸载旧包。

## v6 → v7：星辉矿脉

原字段整体保留，包括钻石、原矿、全部小京任务/记忆/试炼/婚姻、三属性、第一章发展方向和操作模式。新增`mines`与`chapter_two`，不把旧路线盘奖励折算成新矿区奖励，不在迁移时结算任务。

旧档已完成的小京试炼、已获得的钻石和婚姻全部认可，不要求重做。旧`cave`非空时标记`legacy_board_claimable`，可继续原位置与气囊或撤退；退出后置`legacy_board_settled`，新旧入口都不能重新开路线盘。新矿道试炼共用原`trials`完成ID，不能重复发通过奖励；记忆副页共用原七份记忆ID，不重复增加数量。

矿区进入受第二章解锁约束，恢复时先校验整份状态，再重建地图/机关/矿脉碰撞，随后检测位置。新位置仍合法但落在障碍中时，回当前矿区安全入口，其余数据保留。运行路径和待执行动作不存档。

损坏主档回退`.bak`后再次保存，不再用损坏主档覆盖有效备份：损坏内容移到`.corrupt`，保留可恢复文件。独立进程测试覆盖v7队列、矿脉、婚姻、操作模式与重启后的寻路，另有损坏主档恢复后再次落盘检查。所有测试使用隔离目录。
