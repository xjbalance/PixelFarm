# 四季万象玩法速查

## 恢复体力与精准操作

浇水会短暂锁住人物脚底和朝向，视觉反馈从固定原点计算，结束不会漂移。鼠标/手指按下时记录世界点，地图UI点击不穿透。设置随时切点击/摇杆，切换取消旧路径与待执行交互。

屋东休息椅每日3次，每次+15体力/20游戏分钟；23:40起不够时间，满体力不占次数。菜单有“体力恢复”帮助页，真正休息需到椅边。原床白天仍不能睡。背包三基础作物可作每日3份零食，原茶座每日+40，料理每天共享一份，不无限叠加。

## 钓鱼与鱼栏

第9工具鱼竿。点可钓水域→走合法岸位→面板抛竿→等待咬钩→按住/松开追鱼区。空格同样操作，按时间步积分。每投一份鱼饵与基础3体力（节能餐会降低），失败或取消也计本次；每日跨地点共用总计数，通常最多12，低生态降低湖区可用次数。

竿2/3需经验和真实木矿工艺。钩有30次耐久；钓获图鉴/成就保存。满包成功鱼放桶中，腾位只领一次。普通亲鱼可经有成本培育成为原同ID鱼苗，稀有品种仍守原矿区/研究条件。

鱼栏原六鱼与三级容量12/20/32保留，新增全湖生态70起步。每栏超过八成容量、差水质和风暴淤积会缓慢影响生态；清理、种水草、修循环、合理收获可恢复，不团灭。生态90以上加快合适幼鱼，35以下放慢但仍可养成。水样台有明确管理与环保委托。

永恒星鲤：原520播种解锁、适当小京共同照料、三级竿、高生态与流星夜20点后等条件一起满足。有限保底遇见仍须赢小游戏；每季一尾，售价0，不换钻石。

## 畜牧与厨房

农场南三牌建舍→买幼畜→每日喂食/抚摸→成长后收鸡蛋/牛奶/羊毛。各舍三等级容量2/4/6，升级保留动物。动物有实际位置与动作，冬季/雨雪回暖舍需饲草，晴日08–14点可以开牧。漏喂慢产但不死亡；满包产品留在舍内，积存有上限。

小屋厨房基础炖菜可做；磨坊、奶酪台、熏鱼炉、果酱锅另建。4队列、每笔至多8批，按游戏日完成，满包留成品，工作序号只领一次。野莓丛在原农场，冬季少采，材料不依赖尚未解锁地图。

## 节日与人物

每季24日，手记看日期/预报。春赛先腾三空格，再新种至少两类并照料；奖励含原种子、纪念与可栽种春铃花种。夏需两次实际钓获和两位现场村民交流，20点后选灯。秋准备本季真实新产、至少两类共3–6份交付展篮。冬报名后原厨房新做三份暖锅，亲自送达林芽/周砚/阿禾。

NPC主对话保留，标题“近况与礼物”开个人页；小京独立面板有“四季近况”。手记邻居页/地图显示实际地点。生日春6林芽、夏14小京、秋9周砚、冬3阿禾。日聊/赠礼限制与重复礼物反馈，所有个人事件需真实行动与现场结算。

小京湖约失约可用新收获/新烹饪重新约；新增季节支线不阻断旧婚礼。她仍做水样/记录与自己的计划。旧三属性100、12专属、7记忆、5试炼、温室和1314钻石要求保留。

## 家园、特殊花与月夜

小屋西图纸台制作/扩建/储物；二级打开左侧小间，三级打开宽工作间。按面板选家具和格子、预览尺寸再确认。只能专用安全区，不占床门/厨房/故事与穿行路。已摆件点后自动靠近，可移动回收。柜存2/4/8种，各999上限，满包取出整笔取消。

在庭院摆好“四季花坛”，靠近点开→播一粒春铃花种→过3个游戏日→点成熟标记采一朵。可移动但不早熟，撤苗退一粒，满包保留原种植；先采/撤再回收花坛。庭院播种不计原合法农田520次，花可送林芽，仍每日一次。

每季15日20点后若晴或薄云有特殊月夜。到原湖岸水样台记录倒影，得唯一月影笺；雨雪雾夜不伪造观月。流星夜与月夜独立，日历仍只九种天气，旧天气预报不重抽。

## 隐图与世界发展

农场西北林门→森林四季刻痕/分散符桩→隐藏径与档案。修好湖泊生态后去湖东旧阶核对排水牌→封闭干检修廊→退水、分流、露桥→第二档案。前两档案和高级矿道/星纹镐后去河湾村东岸石门→校镜、符台→神庙档案与长期收藏。出口一直保留，错误可重试，箱子唯一；两处隐图钓点复用原钓鱼系统。

村庄共建发展牌开放两条两级路线：码头现场接单后真实新生产再交货，三日间隔；社区三处实走巡灯、18–22点值日，每周第六日原村民实际聚集共餐。第一章三方向改变推荐/补给，都能建设另一条路线。所有变化和四季外观叠加保存。
