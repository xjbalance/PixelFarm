# 0.7.1《匠心打磨》精细化任务01：点击移动与智能交互

本轮只优化输入意图接管、自动行走停止与交互目标有效性。实际起点是`eae7656`（0.7.1、schema v22），工作区开始时干净；`5323ce2`是之前0.7.0历史基线。本轮没有回退既有提交，没有改版本元数据、存档结构或玩法。

## 审查与复现

阅读了TouchInputManager、Player、WorldNavigation、AutoMoveController、InteractionResolver/Executor、Camera2D场景配置、UI触点过滤及各目标的碰撞/距离接口。生产改动限定两个脚本；相机、网格算法、玩家动画、农作物/NPC剧情、矿洞难度、资源经济、睡眠与恢复均沿用原实现。

| 实际问题 | 原因 | 本轮修复 |
|---|---|---|
| 按住新地面时旧农田仍被浇水并扣1体力 | 新意图仅在释放时替换，按下至释放期间旧路径仍推进 | 合法主指/鼠标地图按下即取消旧路线与待交互；释放才提交按下时的坐标和对象。UI、拖动、多指原过滤保留。 |
| NPC已在合法交互圈仍多走一段 | 只在路径游标全部走完时尝试交互 | 地图物件/资源在原距离和视线合法时提前停止；动态导航dirty优先处理，执行器继续复核。地面与农田不提前缩短终点。 |
| 工具动画期间短按方向键后，仍会执行之前自动任务 | action_time提前return，跳过手动输入取消判定 | 先检查取消条件与目标有效性，再等待动作。 |
| 途中已耗尽矿脉仍被追踪并调用一次 | 点选时有active过滤，但移动刷新只检查农场资源耐久 | 对矿区/深渊目标同步active有效性，失效即取消并清除目标反馈；不修改采矿结算。 |

原按下世界坐标锁定、相机逆变换、UI防穿透、多指过滤、模式/地图/模态取消、浇水脚底与朝向锁定均继续通过。没有复现新的错误方向、来回横跳、到达后持续行走帧、隔墙交互或浇水精灵漂移，因此没有重写相关部分。

矿脉失效用受控夹具模拟节点在途中耗尽，证明状态安全边界；没有据此声称正常单人流程有某个发生率。两次完整点击同一矿脉/树木仍可各采一次，未加全局同目标去重。

## 可测量差异

正式专项中的同一个NPC场景：首次进入合法交互圈之后，额外移动**20.4996px→0px**，至执行等待**10→1物理帧**（60Hz约166.7→16.7ms）。另一独立探针因站位不同测得19.3335px/9帧→0px/1帧，结论一致，未混用不同场景数据。

新地面按住期间旧农田的体力扣除**1→0**、旧浇水执行**是→否**；随后正常释放仍抵达新目标。动作等待中手动取消后，旧意图执行**1→0**。已耗尽矿脉的无效移动**95.417px→0px**，执行调用**1→0**（修复前也由业务层拒绝，未实际扣采矿资源）。

远距离移动的单物理帧最大位移维持**2.416707px**，等于原145px/s速度在60Hz的量级，没有瞬移、加速或精灵插值改造。地面停留仍按原32px格心及约1px到达容差。

## 测试与实际画面

完整基线实际执行3090自动化与706桌面窗口检查，零失败。原代码新增专项46项中44项通过、2项失败，两项失败对应同一个NPC过走问题的距离与时延断言。补齐其他已复现问题后，专项53项通过；独立写入与重启进程2＋3项通过。最终完整回归为**3146项自动化断言（3141项主套件＋5项独立写入/重启）、765项窗口检查，全部零失败**。旧矿洞套件按实际消耗触发的“有限随行补给”分支少执行两次，因此该套件448→446条断言；原测试未删改，不用机械相加虚报总数。统计见`TOUCH-POLISH-01.json`和以下最终日志。

- `builds/touch-polish-baseline-check.log` / `touch-polish-baseline-window.log`：本次真实基线。
- `builds/touch-polish-runner-before.log` / `touch-polish-metrics-before.json`：专项修复前。
- `builds/touch01-nav-probe-{before,after}.log`、`touch01-input-probe.log` / `touch01-input-probe-after.log`：独立复现和修复后对照。
- `builds/touch-polish-final-check.log` / `touch-polish-final-window.log`：完整回归。

53项专项覆盖近/远地面、拐角、不可达区域、NPC、农田、树石/矿脉、鱼栏岸边、建筑入口、跟随相机及1.6倍缩放、三种宽高比、快速改目标、同手势重复释放、UI/多指、摇杆切换与使用、换图、停止动画、浇水恢复、失效目标与短按手动取消。原完整回归继续覆盖桥梁、家具、动态障碍、矿石清除/再生和100层地图。独立进程验证原存档版本/模式、加载无旧路径，重新切回点击能正常移动。

另有6项真实渲染检查，记录136个移动物理采样与10张实际窗口帧。已查看拐角方向/站位、到达后待机帧、浇水脚底与横向精灵原点：未观察到累积漂移，数值断言同时通过。像素纹理和相机插值未改。此结果是Linux Xvfb/Mesa实际渲染及原生触点模拟，不代表真人手机手感。
