# 数量出售、农场视觉样板与羊皮纸地图交付

基于`0ac1b78`增量开发。按用户要求分为三个独立提交：数量出售`d973328`、农场样板`cac470b`，羊皮纸地图为随后独立提交。没有重建项目，`need/`参考原图保留在本地且不提交或打包。

## 可直接使用

- 到种子摊选择“按数量出售”，默认1个；可用加减或1/5/10/全部选择，再核对总价和剩余数量后确认。原“出售全部”仍可使用，失败、取消、旧确认或重复点击不扣物品。
- 农场以低噪声草块、成簇细草野花、自然土路边缘、浅岸线与三种树冠统一四季视觉。仅改农场，保留原坐标、地形碰撞、60块农田和42个采集点。
- 按M或点右上方小折图标查看羊皮纸地图。世界总览和区域详图可拖动、缩放、查看地点、定位人物；原手记从HUD或菜单按钮进入。地图仅供查看，不传送、不替玩家交互。

## 原创资源与修改范围

18张农场PNG、34张图纸PNG和1张地图入口SVG由本项目原创生成器维护；最近邻显示，沿用Noto中文字体与许可证。四个参考HTML页面访问成功，Stonebit页面TLS失败；实际查看了Cainos Basic预览图，未下载商业瓦片包，也没有把参考预览导入或分发。没有调用图像生成API。

生产改动包括农场视觉层、土壤绘制、仅农场的季节分支、商店数量确认，以及独立的`atlas_data/atlas_canvas/atlas_panel`。HUD和主场景仅接入入口与菜单生命周期。具体文件和实现分别见[出售报告](SALE-QUANTITY.md)、[农场报告](FARM-VISUAL-06.md)、[图纸报告](PARCHMENT-MAP.md)。

售价、成长天数、资源掉落、住宅费用、睡眠和剧情条件均未调整。图纸直接读取原桥梁、生态、住宅、温室和探索状态；保存版本仍为v24，没有新增地图持久字段。

## 最终验证

完整[机器记录](TEST-MAP06.json)：**4598项自动化、2869项桌面窗口、142个计划进程全部通过**，30套窗口检查零失败。

专项覆盖所有农田与资源可达性、真实种植/浇水/收获/采集再生、四季物理格一致、四级住宅入口、数量出售只结算一次、地图原生手指及鼠标操作、未知区域遮蔽、修桥前后变化，以及16:9/19.5:9/20:9/平板与安全区/DPI注入。当前和真实v23旧结构四个独立进程45项持久化检查通过，原钱物、家具、柜存、施工和婚姻逐字段保留。

首轮旧UI检查未登记新弹窗而报覆盖遗漏，已加入真实地图公开入口并保留全部原断言；最终UI04为916项、UI05布局308项通过。展开首帧宽度、严格数组类型与世界总览断桥表现的集成问题均修复，含错误的中间运行未计为通过。

原签名Android调试APK已构建，包名`org.pixelfarm.windbud`、versionCode17、双ABI；实际包内资源在隔离桌面Godot启动180帧及接口验证通过，53个新美术导入记录与纹理载荷齐全。真实SIGKILL后独立重启通过。APK为68,431,285字节，SHA256：`7284f7cf0b434265b9e3a7a852820b3ebf1343c72972335174ef8161fe054217`。

## 尚待验收

没有Android真机，手机双指手感、实际DPI/挖孔、覆盖安装、帧率和内存待验收。村庄、森林和矿洞的实际场景美术本轮未重做，须先由玩家查看农场样板。

发现既有`WorldChanges.derive()`仍将住宅等级限定到3，四级时派生features可能为空；本轮只记录，未扩展修改该系统。实际住宅由原`HouseExterior`维护，图纸直接读取权威状态，四级外观及地图图标专项通过。

本轮交付后停止，不自动开始其他地图或新玩法。
