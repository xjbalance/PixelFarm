# 河湾冒险图纸：可展开羊皮纸地图

本轮为《像素世界》0.7.1 增加独立的地图查看模块。米色羊皮纸、暖棕描边、像素树冠、道路、水岸和建筑符号沿用“河湾手作 · 星辉田园”色调。图纸由原创插画与实时地标组成，不是缩小 TileMap 截图，也不代替场景探索。

## 如何打开与查看

- Android：点击 HUD 安全区内的小型折叠地图图标。
- 桌面：按 **M** 展开或收起；原“手记”继续从 HUD 和菜单进入，按钮不再标注 M。
- “世界总览”查看各地区；“当前区域”查看玩家当前场景；点地点读说明，再用“查看详图”进入已发现区域的图纸。
- 单指拖动，双指缩放；桌面鼠标拖动、滚轮缩放；也可点“＋／−”。缩放限制为 100%–300%。
- “定位人物”返回玩家标记；“收起 ×”、M、Esc 或原系统返回流程关闭地图。

工具动作进行中会提示先等动作结束，再打开地图。地图按原模态规则暂停世界，取消自动寻路和待执行交互；关闭后可正常点击移动或使用备用摇杆，旧路径不会重放。地图不能传送、不能自动导航到其他地区，也不消耗体力、交易物品或完成剧情。

展开过渡为 **0.16 秒横向裁剪**：完整尺寸的图纸在裁剪容器内展开，中文和像素图不随过渡缩放。快速关闭会终止 Tween 并使旧回调失效，避免重复展开或窗口残留。底层场景在整个过程中仍受模态输入拦截。

## 图纸内容与真实世界

| 图纸 | 实际数据依据 |
|---|---|
| 世界总览 | 农场、河湾村、东湖、迷雾森林、矿道入口及已发现的湖底遗迹、古老神庙、星光温室；区域间为拓扑示意，不假装共享连续坐标 |
| 农场详图 | 原住宅门、农田、种子摊、修缮台、委托板、南侧三畜舍、原 42 个树石采集点；采空状态读取原稳定资源 ID |
| 河湾村详图 | 茶屋、周砚木作、水井、旧桥、风灯架、共建板、已开放矿道入口及建成码头等实际点位 |
| 东湖详图 | 农场东湖的局部图纸；四岸鱼栏与水样台对应同一个农场场景，不增加湖泊传送地图 |
| 家内详图 | 当前等级的 `HomeLayout` 房间范围与已确认家具锚点，搬动床、沙发和厨房后随之更新 |
| 矿洞图纸 | 已开放矿区的出入口、当前深渊层及已保存深度/检查点说明，不提前绘出 100 层地形或宝箱 |
| 隐藏区域与温室 | 根据既有解锁、调查事实与修复阶段显示；未知区域只留雾色轮廓和“尚未探索”，不提前暴露名字或具体机关答案 |

世界总览与村庄详图都显示旧桥状态：修桥前为水面断路，修桥后为木桥。住宅图标反映四级形态；湖泊完成恢复后增加水草标记；温室完成修复后有克制的暖金星点。相关说明均直接读取现有进度。

玩家标记在世界总览使用区域位置，在区域详图使用玩家真实世界坐标。农场、室内、村庄、矿洞分别映射，不把进入小屋后的坐标套到农场上。标签与点击范围跟随同一转换，放大和拖动不会让标记相对地点偏移。

## 模块与坐标接口

新增文件：

- `scripts/maps/atlas_data.gd`：只读区域、地标、解锁状态与坐标映射。
- `scripts/maps/atlas_canvas.gd`：图纸绘制、玩家标记、地点命中、单指/双指/鼠标手势。
- `scripts/maps/atlas_panel.gd`：展开窗口、轻量动画、定位/缩放/详情按钮及模态生命周期。
- `assets/maps/`、`tools/generate_atlas_assets.py`：原创建图资源和生成源。
- `assets/ui/map_fold.svg`：HUD 小型地图入口。
- `tests/atlas_core_runner.*`、`tests/atlas_ui_runner.*`、`tests/atlas_persistence.*`：状态、窗口与跨进程验证。

画布接口为 `setup(game)`、`show_world()`、`show_region(id="")`、`center_player()`、`zoom_by(factor)`，只读展示 `layer_id`、`region_id` 和 `zoom`；`place_selected(info)` 提供名称、说明、区域、发现状态与图纸点位，`view_changed` 通知视图变化。

图纸设计空间为 1024×640，区域坐标按 `(64,48) + (世界位置−区域原点) ÷ 区域尺寸 × (896,544)` 转换。农场范围为 1536×1024，村庄和通常探索场景为 1280×896；东湖裁取农场 `(864,384,544,512)`，室内使用当前等级 `HomeLayout.map_rect()`。图纸坐标再经相同的缩放和平移绘制图标、标记、标签和触控命中。

地图画布消费自己的手势，不调用世界相机或寻路模块。双指、取消、多指与混合鼠标/触屏手势不触发地点点击；双指松开一指时同步平移参考点，避免余下手指拖动跳变。标签保持独立中文字号，并避让相邻标签。按钮沿现有 `UIMetrics` 做触控目标换算，没有将 dp 直接当作世界像素。

## 素材来源与参考边界

`assets/maps/` 共 **34 张原创 PNG**，包括 10 张区域/总览底图与 24 张地点符号。`tools/generate_atlas_assets.py` 使用 Pillow 绘制像素树冠、地形、房屋、水岸与纸面纹理；原生小尺寸符号和图纸采用最近邻显示。现有合法 Noto Sans CJK 负责中文，原字体许可保持。

本轮实际查看了 Cainos Basic 参考预览图；五个素材参考链接中四页可访问、一页因 TLS 失败未打开。其余可访问页面不等于已经查看其中所有素材图片。本模块借鉴地图信息组织和田园氛围，未下载商业瓦片包；参考预览仅保留在本地构建目录，不导入游戏或随源码/APK分发。未调用图像生成 API。

## 存档保护

沿用 **v24**，本模块不新增持久化字段。未知区域、修桥、生态、矿区、深渊检查点、住宅等级和温室状态来自已有存档；地图缩放、拖动、选中地点与展开动画是临时查看状态，重新打开或启动不触发奖励、不重放世界操作。

真实 v23 文件通过现有迁移进入 v24 后可查看地图，当前 v24 也可独立重启恢复。地图不重置农田、家具、施工、钱物、小京关系、婚姻或矿洞进度。

## 专项实际验证

集成时实际修正了四类问题：Godot严格类型下空资源数组的三元表达式赋值错误，改用明确分支；面板首帧尚未完成布局时展开目标宽度为零，改为等待布局并用打开序号取消旧动画；总览底图桥梁最初未反映断路，补上与详图一致的进度覆盖；旧UI04/05全弹窗覆盖清单缺少新地图，补入真实公开入口检查，保留原有覆盖断言。含错误的中间日志不作为通过记录。

最终整合回归为4598项自动化、2869项桌面窗口、142个计划进程全部通过，见[机器记录](TEST-MAP06.json)。以下专项结果已包含在相应总数中，不重复相加。

| 检查 | 实际结果 |
|---|---|
| 核心无头状态 | 74 项，0 失败 |
| 核心真实桌面窗口 | 80 项，0 失败；含实际总览桥位修复前后的像素差异 |
| UI 无头状态 | 51 项，0 失败 |
| UI 真实桌面窗口 | 51 项，0 失败 |
| v23 / v24 跨进程 | 4 个独立进程，45 项，0 失败 |
| 横屏与密度 | 16:9、19.5:9、20:9、4:3，以及 64/96 逻辑触控目标的 DPI 注入样本通过 |

专项覆盖展开/收起与快速开关、原生地点轻点、拖动、双指缩放不误点、缩放边界、玩家与室内坐标、桥梁与探索遮蔽、住宅/温室状态、UI 防穿透、关闭后移动恢复，以及地图查看不改存档业务字段。

核心日志：`builds/atlas-core-unit.log`、`builds/atlas-core-window.log`。画面测试来自真实 Linux Godot 4.3 Xvfb/Mesa 窗口，不是 Android 运行。**没有 Android 真机**；手机双指缩放手感、真实 DPI/挖孔安全区、覆盖安装与性能仍待验收。
