# 一键传送回家

当前主界面右上角、地图图标左侧新增“回家”。单次点击直接到小屋内门口附近安全位置；不消耗金币、钻石、物品、体力或游戏时间，不睡觉、不补体力。按钮和图标沿用现有羊皮纸主题，完整九格工具栏保留原尺寸。

按下时立即取消旧自动路线和未生效农活，抬手确认才传送。动作已生效的种植、浇水或采集结果保留，避免重复扣除或领取。传送后清理速度、摇杆、旧触点候选和自由观察，镜头恢复跟随；已在家时按钮禁用，不反复移动角色。

落点优先为门锚点`(640,556)`往屋内20px；依据当前住宅等级、已移动内置家具、玩家家具及NPC选安全站位。默认出生点`(640,500)`可以被家具占用，不拿它当作固定传送点。无安全落点时显示提示并保留原位置。

菜单、对话、角色选择、后台、恢复/结算、午夜和正式婚礼演出阶段暂不可用。矿洞考察中保留原出口回程要求，避免回家恢复体力后绕过试炼条件；普通矿区、隐图及深渊可以回家，空气、层数、检查点、矿脉与救援计数保留，不调用救援或自动完成考察。婚礼准备阶段按原出口规则可离开，演出中暂禁。

回家会走正常到访家中的事件，因此原有“到过家”事实可正常记录；没有额外发放回家奖励。到达后沿现有自动保存机制保存家内位置，重启不会重放旧路径或传送。schema仍v25，没有新增存档字段。
