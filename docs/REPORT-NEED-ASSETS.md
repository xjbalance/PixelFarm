## 已接入的素材与效果

四位方案 C 角色行走资源与用户角色包逐字节一致，继续复用既有主角切换与小京联动。本轮另接入 **97 款世界素材**：树木13、草花9、地面道路8、水域10、庭院家具8、围栏通行11、生活杂物10、公共设施9、建筑门窗11、星辉物件8。

采用32px网格档和最近邻采样；原生Sprite、40张动画帧、7套47形状连接地形、6种围栏重复模块共150份文件按SHA验证。10套四帧动画在运行中播放，草地、道路、树木、农田干湿土、村庄及森林地面使用同套材质。四季色板和无缝水面为适配衍生，未改地形坐标、作物ID或水面碰撞。

住宅、种子摊、茶屋、木作坊、温室及已建畜舍换入对应外观；路牌、信箱、公告栏、风车、休息椅、庭院台、野莓和水样台同步换图。已建与待建状态、动物暖舍、建设等级、温室修复与婚后灯光保留。室内使用源包中适用的椅子、花盆、窗户与灯具，布置预览与实际显示统一；床、沙发、灶台等没有独立新素材的家具继续使用现有资源。

四级住宅外观以包内**一座农舍**衍生配色、花饰和星辉细节，保持原入口与192×168画布；这不是包内提供了四套不同建筑。完整来源与逐项尺寸见[素材审计及缺口](NEED-ASSET-GAPS.md)。原 `need/` 未修改、提交或装入玩家包。

## 农场如何自由改造

游戏内打开 **菜单 → 建造 / 改造领地**，选择地表、植被或设施；分类内可切换分组。点击或拖动进行预览，确认后才提交。支持批量铺地、物件移动与拆除，箭头只移动观察视野。取消和退出不保存悬空预览。

- 9种地表操作：景观翻土、草地、泥路、石路、木路、花圃、沙地、碎石、恢复自然。
- 98个兼容旧ID的放置目录条目，对应89种源物件；树、幼苗、花草、水景、庭院家具、围栏、杂物、灯具与星辉装饰均可摆放。
- 移除原先覆盖大片农场道路和庭院的禁改矩形。原道路、空地与未开垦田地可重新规划；真实农田记录、建筑实体、水面、入口和必要站位保留。
- 原树石须正常采集。采尽后可在原位置铺地或摆件；改造存在时不在原点再生，清除改造后按原日期恢复，不额外发放材料。
- 摆放会检查实际碰撞及可达性。隐藏的季节、剧情功能点也参与通路检查；实际围栏测试中第10段会因封路而被拒绝。
- 新木箱与旧收纳箱访问同一份住宅库存，容量不增加，移动、拆除与重启不复制内容。

| 实测状态 | 可改造地表/全图1536格 | 占可编辑内圈1380格 | 允许固体物件的许可格 |
| --- | ---: | ---: | ---: |
| 初始资源仍存活 | 1087（70.77%） | 78.77% | 925 |
| 原资源采尽后 | 1248（81.25%） | 90.43% | 1076 |

以上为权限与保护格统计，最终放置仍要通过碰撞和通路检查，并非每个许可格都能容纳任意尺寸物件。旧版静态Catalog的160格结果是另一统计口径，没有将其当成旧版实际窗口测得的百分比。

“建筑景观”仅用于装饰，没有生产、入住、仓库扩容或传送功能。景观土壤和新树花草不增加资源产出，真实耕种继续使用原60格及原规则。公共区域、地下地图、经济、时间、小京关系与婚礼条件不变。
