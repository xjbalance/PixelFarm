# 0.6.2湖泊养殖经济模型

本报告来自 tools/simulate_aquaculture.py 的实际执行：六鱼×两种经营策略×1000组，共12000组，每组112游戏日；另对每种鱼做1120日保种延续。随机种子620000。**这是模型，不是真人试玩或实际操作时长。**

规则读取当前fish.json。假设94%投喂执行率、需要时92%维护执行率、随机起始季节；三级栏使用预存饲料。饲料均按4金/份计成本，稀有鱼材料按放弃出售的机会成本计入。没有计入设施资本、工具、行走、菜单、体力机会成本或料理利润，因此不能把结果视为净劳动收入。

普通鱼提供与农田并行的有限产能：单栏容量12/20/32、总计最多4栏，必须投入鱼苗、饲料与维护。保种繁殖更省苗源，但收益通常低于普通鱼按批补苗；稀有鱼按批换苗再出售成鱼会亏机会成本，定位为收藏与研究、长期保种目标，不是更高等级的纯利润阶梯。

所有模型样本都能首获，长期检查没有容量溢出，并观察到持续繁殖收获。稀有苗可重复培育，普通苗和饲料可持续购买/制作；漏喂不删除鱼群，满包不丢鱼，满水质生态栏可以免费检查，均有运行测试。上述不证明所有玩家行为或任意状态均无死锁；实际经济与照料负担需正常从新档试玩校准。

养殖不产钻石；小京羁绊+3只一次，原520播种、三属性、记忆、试炼、温室、1314钻石与婚姻要求保持。不会以养殖奖励代替矿洞终局。前一版本钻石模型不因这份湖泊现金流估计而自动变成新的全程时长结果。
