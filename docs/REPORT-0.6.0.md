## 3. 小京支线与婚后内容

六幕仍为：第520次播种→荒废的温室→山谷里的秘密→七份遗失的记忆→星光重新亮起→第1314颗星星。原任务ID、基线计数、结语、三属性与结算保持；新增调查用于实际发现和因果衔接，主线NPC不被小京替代。

## 8. 性能与经济模型

采用单个当前楼层实例、固定40×28网格、静态导航缓存、已走格哈希缓存、每层≤16实体、单盏无阴影玩家光、星灯批量绘制，退出统一清理音轨。桌面无头首次百层流程测得地格/节点重建P50 **0.550ms**、P95 **0.607ms**；这是重建函数主线程时间，不含物理同步、寻路与GPU，也不是手机加载/FPS。Godot静态分配统计约116.26MiB，峰值122.40MiB，非安卓RSS或显存。

| 10000次假设模型 | P10 / P50 / P90小时 |
|---|---|
| deep_diamonds，额外消费0钻石 | 29.77 / 35.53 / 41.34 |
| all_rare_and_refining，额外消费0钻石 | 31.27 / 36.97 / 42.82 |
| deep_diamonds，额外消费100钻石 | 30.47 / 36.31 / 42.01 |

模型从当前地图/矿种/配方/护具读取并检查资源前置，无需买到尚不可采的材料来升级。深层钻石20矿保底均值25/三日；全部星辉原矿和钻石加精炼均值78.333，但原料、燃料和采矿至少867体力，不能假设一天完成，模型按最大210体力/日至少五日。旧来源继续可重复，箱子耗尽不致死局。

以上是明示操作时长假设，没有真人完成时长数据；既往200–350小时目标仍未达到或验证，不能把睡眠日历下界当作有趣内容或拿极低掉率凑数。
