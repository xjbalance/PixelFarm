# 《像素世界》美术风格基线 · 0.8.1 丰收匠心

审计来源：实际提交 `14287b5`、`project.godot`、资源目录和运行中的 Godot 场景。逐文件尺寸、颜色与校验值见 [原始审计](quality081/art-baseline.json)，[素材联系表](quality081/art-baseline-contact.png)。联系表只用于查找差异，视觉验收使用同一游戏场景的窗口截图。

## 真实工程状态

- Godot 4.3 Standard，0.8.0《丰收工坊》，存档 v28，Android code 30。
- 33 种田间作物：原胡萝卜、土豆、小麦，以及27种季节作物、3种花卉；4种结果树。
- 10类实体设备、49条分钟加工配方；旧厨房4条按日工单仍兼容；32道厨房料理（旧5＋新27）。
- 鸡、牛、羊有实际成长、喂养和产物逻辑。鸭、山羊、猪、蜂箱及可食用蘑菇来源未实现，只保留明确的扩展记录。
- 当前田间作物均单次收获，收获后清空植株；只有结果树支持成熟后重复结果。本轮不为草莓、番茄等擅自增加再生收获。
- 当前温室承载剧情、婚礼和已有活动，没有普通田间种植接口；种子说明不能宣称可以在温室绕过季节。

## 像素密度与占地

| 新作物 | 每种128×40，4列；原生32×40 | 体块和根部对齐；1像素仅用于轮廓、高光和识别性细节 |

## 配色、光照和形体

继续使用 `resources/presentation/world_palette.json` 的晴光河湾89色阶，以及UI04的羊皮纸、暖木和深栗棕。明亮度来自浅草地、奶油高光和有节制的明暗层次，不能统一套灰褐滤镜。

光源固定左上；受光面在上缘/左侧，接触阴影在底部。每种材质通常采用轮廓、暗部、中间色、高光四级，最多五级。轮廓使用深绿棕 `#414c42` 或暖木深色，避免大面积纯黑和双重厚描边。

- **植物**：2像素叶片体块配1像素叶脉；区分根菜、叶菜、矮丛、藤蔓、谷物、高秆和花卉。成熟植株应有真实的植株结构，不能只是把完整背包图标贴在同一根茎上。
- **木材**：暖木阶，短而连续的纹理、拼板缝和一两个扣件；不铺满随机噪点。
- **布料/面粉袋**：奶油色大面、侧面褶皱与收口；区别于金属容器的硬高光。
- **铜、铁与玻璃**：锅沿、把手、立边使用短高光；果汁保留液面与透明感，不用大块刺眼纯白。
- **食物**：面包表现切口、圆润体积和底部烘烤色；酱/油/腌菜沿用一致瓶罐比例，但标签和内容物必须可区分。
- **地图与人物**：不重画已有合格建筑、角色和地面。农业素材增加细节时保持相同像素尺度，不能靠模糊放大“变精细”。

## 动画与反馈

人物沿用6fps，动物沿用4fps。设备使用4帧、4fps的小幅手柄/梭子/蒸汽动作，动画画布32×56仅在顶部增加8像素烟气空间，脚底保持原位；工作动画只读生产状态，不推进时钟、不调用收获接口。空闲、完成、隐藏、菜单暂停和后台状态正确停止无用刷新。不用粒子群、实时灯或复杂Shader。

成熟提示使用小型暖金标识，浇水提示保留清楚的蓝色与湿土区别；没有任何提示节点参与地图触控命中。

## UI和触控基线

共享 `river_theme.tres` 与 `FarmUIStyle`，正文18、标题22–24、次级16。中文沿用授权 Noto Sans CJK，不像图片一样机械像素化。图标和边框最近邻过滤。

当前实际HUD已经按用户要求恢复完整九格和原尺寸；历史UI05文档中的紧凑三格不是当前目标。本轮只打磨厨房、加工和种子购买界面。

48dp必须通过DPI和实际视口换算。沿用 `UIMetrics`；320/480DPI及横屏安全区以注入样本和实际窗口验证，不能称为Android真机验收。

## 审计发现与实施顺序

0.8.0核心农业与加工功能可运行，未开放动物产线不算本轮已完成内容。优先问题是新作物阶段结构过于相似、旧/新图标阴影层次不一、设备缺少工作反馈、配方缺料提示不具体、列表重建导致滚动位置易丢失、进度文字无须逐帧更新。

A先做草莓、面粉、面包、果酱锅样板；B统一其余农业素材与轻量设备动画；C验证时钟与物品事务；D完善配方、季节购买和非强制引导；E核验五条生产链、成本收益、存档与导出。

验收需同时查看胡萝卜/草莓、小麦/玉米、磨坊/果酱锅、背包内旧新物品、厨房内旧新料理。前后截图固定相机和物品数量；素材对照背包仅在测试夹具里隐藏无关条目，复用真实背包组件与图标，不把单独PNG拼图当游戏画面。
