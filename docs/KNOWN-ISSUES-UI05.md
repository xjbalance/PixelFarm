# UI05验收边界

- 未连接Android真机。真实DPI、刘海/挖孔、手机手势舒适度、覆盖安装、系统回收、帧率、温度和功耗仍待验收；Linux窗口矩阵和APK资源桌面启动不能替代这些结果。
- 默认工具触区按48dp换算，204逻辑px是桌面48px样本，不是所有手机的固定物理宽度；含独立操作按钮为276px。高密度样本会扩大触区以保证可点。
- 地图边缘优先限位，角色可能偏离中心。小屋等小图保持原缩放、对不足一屏的区域填充背景；没有为了绝对居中露出未制作地图。
- 当前工程没有独立标题菜单、新游戏按钮或音量滑杆。本轮统一的是已有的游戏内设置、继续与存读入口，没有添加这些新功能。
- 本轮桌面自动化/窗口未发现尚未修复的阻断问题；这不等于长期人工游玩或其他桌面平台已验收。此前内容范围限制和历史问题见原版本报告。
