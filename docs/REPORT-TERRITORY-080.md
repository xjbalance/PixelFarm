# 0.8.0《开拓家园》第一阶段交付

本阶段完成地表大地图与私人领地编辑底座：原农场保留，新增河东开发地、湖畔归属地、林地开发区及终局庄园用地四张 40×28 地表场景。游戏内打开菜单 →「建造 / 改造领地」，选择工具后点选或拖刷，预览绿色时确认；移动和拆除也需要确认，退出放弃未确认预览。

## 区域与开放路线

[权限和路线表](TERRITORY-080-DESIGN.md)列出全部真实条件。初始只能改造主农场的授权空地；修桥并完成第一章后开放河东；湖泊恢复并完成第二章「地下水位异常」后开放湖畔；森林清障与排水档案完成后开放林地；现有第二章终章完成后开放庄园。

原河湾村、NPC 核心区、节日与剧情区、旧森林调查区、温室礼堂及地下仍遵守原规则。河东北侧过渡带是有限编辑区，只能修改地表和放置不阻路花草。路牌显示具体未完成条件，未授权场景拒绝进入和编辑；图纸不提供传送。

## 可编辑内容

| 类别 | 本阶段实现 |
| --- | --- |
| 地表与道路 | 翻土外观、草地、泥路、石路、木路、自然地表、花圃；最多 128 格一笔，整笔验证提交 |
| 植被 | 观赏树、灌木、草簇、花丛与自然景石，支持原有四季色彩 |
| 小型放置物 | 围栏、灯、小桌、木椅、长椅、共享收纳箱；确认放置、移动或拆除 |
| 安全与通行 | 完整占地、碰撞、人物站位、原门口与路径检查；不能以第四面围栏封死角色 |
| 交互与输入 | UI 和世界手势分开，批量拖刷只产生预览；确认防重复，多指/混合输入不结算；退出恢复原镜头和操作模式 |
| 图纸 | 总览显示四处领地及开放状态，详图显示边界、保留通路、地表差异和关键小设施；原手记使用同一图纸 |

施工用于环境改造，当前不收费、不退款、不发资源。观赏树不产木材，新翻土地表不扩增原有 60 格作物田。共享箱子只提供原住宅收纳入口，容量与物品数据只有一份，搬箱子或拆箱子不会复制或删除柜存。原家具购买、生产、售价、钓鱼、畜牧和矿洞数值保持原规则。

第一阶段上限为 256 件新放置物，单笔涂刷最多 128 格；达到上限会提示，失败不产生部分提交。大型建筑与原有设施不能在这个编辑器中选中或拆除。

## 验证结果

完整自动化入口执行 **172 个进程、6,745 项检查，0 失败**。领地新增专项为核心 112、输入编辑 54、场景/碰撞/通路/设施 89、图纸 35，以及六个独立存档进程 60，共 350 项，均已计入完整结果。修改前 1,015 项基线及重复验证次数不额外累计。

实际窗口检查 **600 项，0 失败**：新编辑 54、场景 89、图纸 35，相关原触控 UI 296、原图纸 84、手记图纸 42。窗口覆盖四种宽高比、屏幕安全区和 480 DPI 注入，包含原生触摸事件；没有进行 Android 真机或实体手柄验收。

Android 调试 APK 使用原包名和原签名，版本 0.8.0、versionCode 23，包含 arm64-v8a 与 armeabi-v7a。另将最终 APK 实际资源提取到隔离目录，在桌面 Godot 检查启动，以及真实打开建造、确认地表、拒绝未开放地区和保存恢复。该验证不能代替手机安装和触感测试。完整数值、日志及 APK 校验见 [TEST-TERRITORY-080.json](TEST-TERRITORY-080.json)。
