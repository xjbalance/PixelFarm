## 扩展断言重点

- 采集必须使用匹配工具，目标必须在面前且在距离内；原有交互按钮真实触发三次砍树并获得木材。
- 错误工具、体力不足、背包装不下完整掉落时，不改变耐久或体力；枯竭对象不能重复掉落。
- 树木采完解除碰撞，玩家可通过；树木 3 天、石堆 2 天恢复；玩家占据再生区域时不生成障碍。
- 采集剩余耐久可保存/恢复；木材出售正确结算。
- 设施先验证全部金币和材料，成功只扣一次；重复修缮被拒绝。
- 工具架使石堆一次采完；卧室改变实际体力上限和 HUD，睡觉按 130 恢复；引水渠仅覆盖 12 格，正确处理先成长、后补水和新开垦格供水。
- 委托前置关系生效；接取、交付、种子/金币/好感奖励、任务完成状态整笔提交。
- 未接取、物品不足、奖励装不下、重复领取或金币封顶都不会产生部分扣除或重复收益。
- 每日交谈好感只增加一次，下一天恢复额度；三份委托形成可完成的连续流程。
- 新存档恢复全部扩展数据，非法设施/重复设施/越级任务/超限好感/无效采集状态会被拒绝。
- 版本 1 迁移保留原金币、库存、位置、日期、体力和农田，迁移不修改输入数据。
- 委托板按钮使用真实触点事件接取任务；随身手记不能交付；背包材料页可以装备采集工具。
- 原有双指输入、模态防穿透、后台恢复、3 种横屏布局持续通过；新增修缮面板同样在 1280×720、1600×720、1280×960 内完整显示。
