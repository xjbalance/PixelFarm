# 0.8.0《开拓家园》· 农场全场 DIY

本轮按“农场所有内容都可自己改造”实施，已经包含真实住宅、商店、温室、畜舍、鱼栏、原有设施、树石、农田和水域。原有内容不再固定在最初位置，也没有上一版的大块永久保留地。占地、地图边界和出入口通行仍需合法，避免把人或功能围死。

实现提交：`84fb5c0`（布局与v27迁移）、`9933986`（全场编辑、业务位置与图纸）。分支为 `development/0.8.0`，`need/` 没有修改、提交或打包。

## 游戏内操作

进入 **菜单 → 建造 / 改造领地**。

- **原物**：选择真实建筑、设施、原生树石或生产田，点地图预览，再确认移动。也可以直接点地图上的物件。
- **收纳**：保留原实例身份及进度；从“原物 → 分组 → 已收纳”选择后，在地图上放回。
- **地表**：重新铺草地、泥路、石路、木路、沙地和碎石；浅水/深水笔刷改变池塘形状，改回草地可填水。
- **摆件与植被**：继续使用上一轮98个兼容目录项；庭院原家具也可搬动、回收和从家具库重新摆放。
- **新农田**：选普通锄头，在全农场合法干地开垦。普通地图点击继续移动，显式选择锄头才在新地开垦。

原物目录按32项分页，另有设施、资源、农田与收纳分组，不生成整张地图的数千个坐标按钮。高DPI下方向键会换到独立一行，避免与动作按钮挤出安全区。

“原物”中的住宅和温室是真实功能实体；“摆件”里的建筑景观仍是装饰，不替代真正住宅，也不提供额外生产、住宿或储物容量。

天然湖泊可整体移动或收纳，笔刷可另外增减水格。玩家确认的地表覆盖按实际格子保存，不会因移动天然湖泊而被自动清掉。水格实际切换原TileData的水面碰撞列，填水后实际可走，不是只换颜色。

## 原进度与经营规则保护

布局独立存为 `farm_layout`，只记录原身份的位置和收纳状态；等级、材料、动物、库存、任务和关系仍由原系统保存。

- 房屋搬迁后保留等级、室内家具、厨房与沙发功能；进屋、出屋和回家站位跟随。出口被其他改造影响时会寻找安全陆地。
- 畜舍搬迁后动物活动范围与交互跟随，原动物逻辑坐标、ID、产物和日结算规则保留。
- 鱼栏、钓鱼、生态台、节日和小京站位跟随对应设施；普通交互不能在收纳后的旧址继续生效。钓鱼浮标无水时明确提示，不扣饵料开始空地钓鱼。
- 搬田保留作物、成长天数与水分，收纳暂停该田生长，放回后继续。原12格灌溉权益随逻辑地块移动，不复制。
- 新开垦与播种继续走原农活事务，体力、种子、成长和收获数值不变；搬田不增加520播种计数。
- 角色形象、小京性别联动、好感、婚姻、钻石与稀有鱼婚礼要求保留。公共地图和地下关卡不开放拆改。
