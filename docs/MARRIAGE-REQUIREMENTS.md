# 婚礼生活准备

在原有小京关系、任务、记忆、试炼、温室、剧情选择、守约及 1314 颗钻石条件上，尚未结婚的玩家需同时完成两项生活准备：

| 目标 | 判定 | 提示 |
| --- | --- | --- |
| 当前最高四级住宅「星光庄园」 | 已完成升级，`Housing.state.level >= 4` | 周砚的建造服务；四级施工中尚未生效 |
| 传说鱼「永恒星鲤」 | `Fishing.state.counts.eternal >= 1` | 必须亲手钓获并领取过；只检查记录，不交付、不消耗鱼 |

按用户确认，本轮不额外要求通关全部婚前主线；原来的主线与百层相关婚礼前置继续按原规则检查。

永恒星鲤沿用现有获取规则：三级星纹鱼竿、农场湖泊、生态健康度至少 90、流星夜 20:00 后、小京已解锁且完成湖畔共同照料研究。该研究可以婚前完成。符合条件的第四次抛竿保底遇到，仍需完成钓鱼小游戏；每季最多一尾。这次不调整概率、时间、生态、鱼竿或研究条件。

鱼在背包、储物柜或其他来源出现不能代替钓获记录。小游戏成功但背包已满时先保留待领取状态，腾出空间领取后才计入；已有记录不要求鱼一直放在背包。

求婚、开始仪式和最终结婚确认均检查目标，旧的未婚婚约标记也不能绕过。取消、条件不足和重复点击不会扣除钻石；最终结婚仍只按原事务扣除一次 1314 颗钻石。关系面板、星光手记、温室准备、两套礼堂确认和传说约定共用同一目标状态与文字。

已结婚的旧档继续有效，无须补交住宅或鱼，不撤销婚姻、不重复收钻、不重发奖励。存档仍为 v25，复用住宅等级与钓获记录，没有新增保存字段，也不向存档合法性检查添加新婚姻门槛。

新增 **69 项状态检查和 69 项实际窗口检查**全部通过，覆盖两日施工、真实流星夜抛竿和追鱼、满背包暂存与领取、记录保存恢复、男女主角仪式、旧婚约防绕过、重复扣钻防护，以及已婚 v24 迁移与重启。原有 **1,632 项状态回归、296 项窗口回归**也通过；基线 1,010 项与重复执行次数不计入这些合计。
