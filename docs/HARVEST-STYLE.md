# 丰收工坊：现有美术基线

基线提交 ccdee21。保留晴光河湾的 89 色阶配置 resources/presentation/world_palette.json，原始 need/ 与旧素材不改写。

- 世界网格 32×32，旧农作物为 32×40 四阶段；新作物沿用相同足点和四阶段画幅。
- 原生单像素轮廓，深绿棕而非纯黑；高光来自左上，阴影位于右下。
- 叶片使用既有浅绿—苔绿阶，木材用暖木—奶油阶；果蔬按既有花色、屋顶和金色阶区分。
- 形体圆润、细节克制，不加抗锯齿、噪点、模糊缩放或烘焙大阴影。
- 金属用石灰与金色短高光；布料用奶油袋身及两级褶皱；食物保留可辨识原料轮廓。
- 背包图标 32×32，主体在 4–28 像素范围内，数量由 UI 单独绘制。
- 设备以 32×32 实际占地、32×48 立面绘制，与旧工台的暖木、石炉、铜扣统一。
- 果树使用现有授权树木的原生树冠造型作为扩展基底；不改变角色或地图尺度。

先验证草莓（种子/幼苗/中期/成熟/果实）、面粉、面包、果酱锅与蛋黄酱；实际窗口分别与原作物、原背包物品、原家具同屏比较后扩展。

验收证据保存在 docs/harvest-workshop，所有画面由实际 Godot 窗口截取。Android 无真机时只报告桌面模拟布局及 APK 检查。
