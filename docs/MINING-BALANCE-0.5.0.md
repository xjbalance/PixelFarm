常规循环约88轮，三日一轮平均14.75钻（直接3.75、精炼6、委托5），即4.917钻/游戏日。当前假设下高级资源阶段平均53.85钻/主动小时，不含前置主线/关系时间。初始一次奖励按晶窟星匣12与七记忆遗匣18计算；旧档库存不额外补发。

主要耗时模型均值：矿洞6.31h、种植/补给13.86h、加工领取/地表往返4.24h、主线/520种植/关系/试炼17.03h。此处没有把三日刷新换算成必须在线等待27分钟；玩家可以安排农场、加工与休息。

地图最短步数与145px/s来自实际地图/角色代码，已解机关、矿脉移除后的路径是行走下界；矿洞主动操作、观察、失误和额外路线使用明示倍率，农场每轮6–12分钟、后勤1.5–4分钟，其他成长10–24小时均为假设。没有记录实际完整通关计时，熟练玩家可能更快。

**80–120小时暂定目标尚未达成。** 三张固定地图与少量固定谜题还不足以支撑这个内容量；不把重复跑图、长等待或无保底低掉率当作补足。下一版应先增加分层路线选择、工具/补给取舍、多套可解机关和探索委托，再用真人主动操作日志校准。

保底机制无“极端倒霉”断供：矿脉不抽随机数，每处至少一钻、每第四处额外一颗，计数入档；精炼产出固定。普通金币商店不卖钻石，低阶区域不产钻石矿，新开旧路线盘已禁用。现有旧钻石与原矿保留。

死局检查包括：普通镐能获得强化镐所需铁铜，强化镐可获星纹镐所需晶石；自然刷新不花钻石；不做委托仍能完成；矿石和树木可再生，售木石可买种子；满包保留矿脉和加工队列，错机关能复位，上行阶梯可回程。模型进行已解地图BFS；Godot另外验证真实碰撞、出入与输入流程。可选付费勘探刷新需要铁锭/合金等补给，不计入常规模型的必需收入。
