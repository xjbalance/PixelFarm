## 新游戏与保存

首次没有存档时先选男女主角，可以反复预选；小京头像自动联动，无独立小京性别选项。触屏、键盘、鼠标和手柄事件均有支持。后台保留未确认选择，取消首次创建不写默认男主档。

已有游戏直接读取，不强制重新选人。菜单“新游戏”先显示覆盖确认，进入选人仍不重置进度；角色最终确认时保留旧档原字节到唯一的`.before_new_game*.bak`，再恢复新游戏初始状态、应用角色并原子保存。取消返回旧游戏菜单；保存失败恢复确认前完整状态并保留重试界面。操作模式和音量偏好保留。

存档从v24迁移至**v25**，只新增`appearance={scheme,player_gender,xiaojing_gender}`。旧版默认农场主按男主映射，自动对应女小京；旧小京三属性、任务、记忆、试炼、婚姻、婚后日期与回信均逐字段保留。当前格式只修复合法主角对应的小京冗余字段；非法主角或未知方案沿原坏档/备份流程处理。[迁移说明](SAVE-MIGRATION.md)

41处确指小京的女性代词改为“小京”或省略主语，两个版本共用原故事。林芽、阿禾的女性称谓及小京母亲身份保留，没有复制两套剧情或改结算。

## 最终验证

[机器记录](TEST-SCHEME-C.json)：**6087项自动化、3425项桌面窗口、159个计划进程全部通过**，36套窗口检查零失败。

新增关键专项：外观/保存44项、六进程40项；选择组件36状态/36窗口；真实主场景54状态/54窗口；首次取消2项。女主深层流程复用原STAR125、LEGEND252、RIVER446项，另26项性别/纹理证据，合计849项。覆盖七记忆、五试炼、1314婚礼、婚后项目与519/520/521回信边界。少量明确旧JSON迁移用例按历史默认回男主，证据如实记录且资源同步。

实际发现并修复：首次取消后退出自动保存会写默认角色，改为不保存未创建旅程；重复创建主场景触发旧厨房显示回调引用已释放节点，改为跟随节点自动释放的绑定方法，未改烹饪规则。旧摇杆菜单测试补先滚入可见区的原生触摸，旧农田图像锚点改核对当前外观脚底，旧版本夹具移除新增字段以保持真实历史格式；原功能断言保留。

原签名Android调试APK已构建，包名`org.pixelfarm.windbud`、versionCode19、双ABI。实际包内资源在隔离桌面Godot启动180帧及接口检查通过，真实SIGKILL后独立重启通过。APK为71,044,092字节，SHA256：`d2140dbff060dfb4114ba4c2143902045fc7b68dbb15c379ef75f177cea59e12`。
