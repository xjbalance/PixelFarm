# 本地试玩诊断（仅开发版本）

Playtest仅在OS.is_debug_build为真时启用。Debug桌面/调试APK默认记录，设置中的“本地试玩记录”可关闭；无头自动化默认关闭，专项测试显式启用。正式Release构建禁用读取偏好、记录和写入。

路径：`user://diagnostics/playtest.jsonl`、`summary.json`、`settings.json`，均与farm_save.json分离。LOG超过5MiB滚动为.previous，累计summary仍保留。没有网络上传代码，不收集用户姓名、设备号、IP、文本输入或文件路径；会话ID为随机短码。

记录实际单调时钟的前台/主动/菜单暂停/后台秒数（不使用加速游戏delta伪造实时时长）、实际跨天天数、成功播种、每层/地图停留、昏睡/救援、矿洞出入、钻石收支来源、真实关系增量、任务与婚礼时间、试炼开始/失败/取消/完成与重试。属性已满时记录实际增量0而非虚假收益。加载存档只记录基线/分段，不补记成奖励。

summary提供当前会话及lifetime累计；playtest.jsonl保留会话/读档分段。多个不同存档或回档重玩不能自动视为同一个新档的最优通关时间，需结合分段分析。诊断损坏/写入失败不阻止游戏，不写正式存档、不改变金币/钻石/日期/任务。累计、重启、去重、白名单与正式快照不变均有测试。

```bash
python3 tools/read_playtest.py /实际用户目录/diagnostics/summary.json
```

建议从全新测试档开始，记录是否使用攻略、探索分岔、日常停留和目标；完成后只在玩家自行决定时导出本地日志。手机数据目录应通过应用调试访问确认；本轮无设备，未执行手机文件提取。不要上传未经同意的试玩数据。
