# UI05《沉浸式视野》交付报告

《像素世界》0.7.1《匠心打磨》，Godot 4.3。基线为 UI04 的 `2a48963`，在原 `development/0.7.1` 分支分阶段开发。起始工作区干净。本轮只调整 UI、相机、手势与直接相关测试；存档版本仍为 **v22**。

## 实际改版

- 日期/天气/体力放左上，时间/金币/菜单放右上；深渊继续常驻显示层数与空气，低空气沿用原危险色。
- 任务默认折叠，背包、委托、手记收进菜单。右下默认三个相邻工具及展开按钮；展开为原索引的 3×3 九格，选择后收起，备用摇杆和独立操作按钮保留。
- 镜头使用 FOLLOW / FREE_LOOK / RETURNING 三种瞬态模式。正常移动跟随脚底锚点；空闲单指拖动只平移画面，松手保持；“回中”平滑恢复跟随。新有效点击使用按下时捕获的世界目标，开始移动后回跟。
- 按下仅记录点击候选，跨过实际换算的 12dp 阈值才拖动；拖动不提交点击。UI 起手、多指、混合鼠标/触屏、工具动作、模态、后台与换图均有取消或拦截。
- 背包/商店采用物品网格和独立详情，查看不消耗；使用、装备、购买与出售沿用原事务。委托采用左清单右详情，分别滚动；对话改为下方阅读区，迟出现的选项向上扩展。
- 厨房/加工、鱼谱/鱼料理、家具商品、节日商品、长期建设使用共享轻卡片；宽度足够时两列，长按钮需要空间时回单列。村民页为小头像概要与交谈/礼物、任务两区；小京三属性缩成概要，纸面与少量星紫标题；设置按功能分组。
- 全部既有模态窗口按类别、安全区和内容定位，复用原滚动、确认、输入屏蔽与回调。没有另建标题菜单；现有游戏内菜单的继续、保存、读取、声音、操作模式等入口保留。

[布局与手势规范](UI05-LAYOUT.md)列出了实际尺寸和边界策略。保留 UI04 的 18 张原创资源；九宫格纹理首次使用时缓存最近邻半尺寸版本，边框从8缩到4逻辑像素，不缩放中文字体和世界贴图。未新增装饰贴图、粒子或 Shader。

| 指标 | UI04 | UI05 |

遮挡指标是**可见且拦截触控的常驻 Control 矩形并集**，排除根节点、模态树和遮罩；不是贴图不透明像素面积，也不是所有场景的固定占比。1280样本相对减少约81.8%。

默认三个48px触区加展开及间距共204逻辑像素；左侧64px操作按钮另计，整个操作区276px。没有为180px视觉建议牺牲48dp触区；64/96逻辑像素为实际DPI/视口缩放换算样本。地图内陆移动及返回样本误差≤2px，地图边缘优先按合法制作区域限位。小屋保持原缩放，用背景填充不足一屏的部分。

原生100屏幕像素拖动在1.35缩放下移动视野74.0741世界像素，玩家位置与资源不变。未进行随机大样本误判率或Android帧率测量。

## 发现、修复与测试

真实基线：3402项自动化断言、1899项窗口检查零失败。最终实际 **3794项自动化、2291项窗口检查、112个计划进程全部通过**，另真实半写异常退出重启通过；统计见 [TEST-UI05.json](TEST-UI05.json)。

已复现并修复的缺口：

1. 原镜头有-60世界像素偏置与平滑滞后；改为物理移动后更新、投影像素取整，移除偏置。
2. 常驻九格及宽面板遮挡；改为角落分组与按需展开。
3. 长对话首次换行前最小高度不稳定，会撑满屏；先给目标宽度，待正文布局稳定再取内容高度。
4. 剧情末尾新增选项会向屏幕下方扩展；改为向上扩展，并在最小尺寸变化后重新底锚。原集成测试三比例曾真实失败，保留断言修复；新增每配置三选项显示/触区检查。
5. 紧凑HUD最初漏掉深渊层数/空气信息；原legend测试真实检出，已恢复持续显示，保留原断言。
6. 设置菜单变成滚动分组后，旧重启夹具在首屏外直接发触点，被原防裁剪规则正确拒绝；夹具改为等待布局、滚入操作模式按钮后用原生触点切换，自动保存与全部逐字段重启断言保留。
7. 旧测试默认九按钮总可见、背包动作总显示；夹具改为真实展开、选择物品后再操作，保留索引、容量、物品/金币/钻石/播种计数等断言。迟到与重复回调检查保留。

新专项为相机48项、快捷栏43项、布局301项。布局覆盖16:9、19.5:9、20:9、4:3、安全区64，以及48dp换算为64/96逻辑像素的校准样本；全部既有模态通过公开入口打开，检查边界、中文横向溢出、可滚入触区与UI不穿透。根代理实际查看了HUD、背包、商店、委托、底部长对话、高DPI对话、厨房、鱼栏、村民、小京记忆和设置画面。

存档结构/迁移代码未修改；镜头偏移、展开状态和选择详情不写入存档。完整回归包含旧档迁移、独立进程重启、备份、真实半写中断、控制模式、农场、矿洞、鱼栏、动物、家具、小京关系/钻石/婚姻与睡眠约束。

桌面性能沿用原压力套件：240次切图，节点1085→1085，静态内存增量22652字节；切图调用P95 0.613ms、寻路重建P95 6.3ms。它们是本机Linux无头CPU样本，切图计时不含延迟呈现，不表示手机FPS/GPU/功耗或长期RSS。
