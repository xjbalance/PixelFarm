# 建筑、角色与界面的统一材质

按用户补充要求，把建筑、角色也纳入这轮风格收口。以既有暖木、奶油纸面、苔绿植被为基准，降低旧角色衣料与建筑瓦片过强的饱和度，补入木纹、瓦缝、布料和窗玻璃小细节。不是给整个屏幕套滤镜，也没有改变世界尺度。

## 实际修改

- 六套角色：玩家四方向十六帧、林芽、周砚、阿禾、小京及原婚礼衣装。保留身份、服饰轮廓与原动画布局，统一暖色皮肤、柔和衣料和左上侧亮部。
- 四座既有建筑：默认房屋、种子摊、茶屋和木作坊。统一奶油墙面、温灰石基、暖木框架及柔和屋顶，补充瓦缝、木板边和布棚折纹。
- 四级住宅外观：保持原等级差异与入口，材料明暗与普通建筑一致。室内家具继续沿用上一轮温馨田园材质。
- 全部HUD及弹窗共用新的细木边羊皮纸组件；不缩小原完整九格、按钮触区、角色或建筑。

14张输出PNG来自本项目`96a9667`的原创素材；生成源保留在`tools/art_sources/style07/`，由`tools/generate_world_style07_assets.py`复现。源文件受`.gdignore`和导出排除规则保护，不额外放入APK；完整源码包保留这些可编辑原始素材。没有下载商业角色或建筑图像，没有调用图像生成API。

## 尺寸与层次保护

逐像素比较全部14张PNG：原尺寸、每个透明度值、角色帧排列和接地阴影轮廓完全保留。玩家仍是128×192帧表，每帧32×48；建筑仍使用原纹理尺寸与脚底定位。没有修改角色速度、碰撞体、图块、房门或NPC坐标。

原农场、村庄和室内已按脚底Y排序。本轮实际画面验证未复现排序错误，因此保留该机制；没有为遮挡效果随意提高角色或建筑的z_index。真实窗口对照了人物在屋后由屋顶遮挡、在屋前正常出现的画面，避免把美术协调问题误改为游戏碰撞问题。
