# 0.8.3 阶段A：背包分组与触控样板

原背包以`Inventory.items`保存物品ID→总量，每种最多999；商店、加工、任务、仓库均使用这些总量。本阶段保留此规则，新增`inventory_layout`保存分组UID、真实格子位置与锁定。六种原有永久工具是既有能力的只读引用，不进入真实物品字典、仓库或丢弃流程。

拆分、交换、同类合并、整理、锁定和丢弃在库存层提交，界面只预览。所有布局提交验证分组总量等于原库存；确认带版本token，数量变化或旧确认回调不能重复提交。整理合并未锁定分组并保留较早UID，锁定格不搬动；快捷栏继续按原物品ID引用，不按显示索引引用。

背包实际采用暖木边框、原羊皮纸、原图标与统一工具衬底。十类筛选由物品`category/kind`定义驱动，未注册重复物品。原鱼饵、鱼钩及永恒星鲤只补充准确的展示类型标签，不改价格、产出或捕获概率。

已实现单击查看、分类保留选择、一键整理、精确拆分（滑块/±1/1个/一半/全部）、鼠标拖动、单指长按拖动、长按松手操作菜单、无效落点返回、锁定保护与明确确认丢弃。先移动的短划手势只翻页，不会晚些转成拖动物品；背包及弹层的触控不下传地图。物品耗尽移除对应真实分组，旧界面回调不能继续消费。

原厨房、加工、食物、装备和种子选择接口继续复用。商店仍由原交易界面负责，后续阶段统一其展示。锁定检查也进入原出售和存入接口，不能靠旧按钮绕过保护。锁定防整理搬动、出售及存入；正常播种、食用和明确的制作材料消耗继续遵守原规则。

存档v30迁移v31，仅增加`inventory_layout`与`ui_preferences`。既有物品、金币、牧场、鸭子、农田、住宅、加工订单、婚姻、任务及操作模式保留。真实v30夹具由`2d427f2`运行生成，附来源校验。可选布局损坏时从原库存重建，不用布局中的数量给玩家补物品；真实库存超过999或含非法物品仍按坏档拒绝。

参考原则采用Stardew Mobile的清楚目标与工具操作、Mistria的信息层级、Sun Haven的数量/转移、Pacha的常用工具和种子选择，延续项目UI05研究。全部实际资源来自本工程，未引入这些游戏的界面或美术文件。
