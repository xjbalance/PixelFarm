## 功能与修复证据

浇水偏移根因是精灵每帧只重置y、横向反馈不断+=；现完整重置位置，浇水不做精灵位移，工具动作0.24秒冻结移动/朝向。新点击可替换意图，自动移动等待动作结束。地图切换清理动作锁，防止上一农活动作让室内首步少走。触控用按下世界坐标，防止相机跟随期间释放到另一格；重复/拖动/多指与UI仍拒绝误动作。

屋东休息椅每天3次，每次20游戏分钟+15体力，午夜前不足20分钟拒绝；生胡萝卜/土豆/小麦恢复8/12/4，每日零食3份，满体力不扣。料理共用原鱼料理每日一餐。恢复不跨日、不让作物/矿石/鱼群多结一次。

新钓竿追加第9工具，前8ID/索引保留；点水走岸，钓点只在选竿时抢对象命中，避免挡共建板。新休息椅缩小点击框，避免普通空地被当椅子。工具栏加宽后仍保留触控检查，不以改变旧预期隐藏问题。

四舍/厨房等场景已做实际碰撞与NPC/床门可达测试；动物最多18只、低速庭院站点、雨雪冬季归舍；生态无掉光鱼死局；满包钓鱼暂存、产品/加工留存，读取不重获奖励。
